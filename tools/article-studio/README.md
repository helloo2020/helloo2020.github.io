# 文章排版工作台

本机使用的 Markdown 排版工具，连接当前 Jekyll 博客仓库。无需安装 npm 依赖或登录其他服务。

## 打开

在 macOS 访达双击博客目录里的 `打开文章排版工具.command`。首次启动时保持终端窗口打开；浏览器会打开 `http://127.0.0.1:4174`。如果工具已经运行，再次双击只会打开现有页面。也可以在本目录运行 `npm start`。

## 使用

1. 粘贴文章，或导入 `.md` 文件。导入时会读取常见 YAML 标题、日期，以及首个一级标题。Obsidian 的 `![[图片.png]]` 会转成图片引用，普通 `[[笔记]]` 会显示为文字。
2. 若文中有本地图片，点“添加本地图片”，选择所引用的图片。图片会随博客文章保存；公众号复制时，本地图片会变成占位提示，需要在公众号后台自行上传并检查。远程图片链接仍由原网站提供，可能在公众号中失效。
3. 选排版方案。可打开“关于我”，填写公众号名称并选择二维码图片。名称和二维码完全由你提供；未提供时不会虚构公众号信息。
4. 点“复制到公众号”，到微信公众号后台粘贴，并检查标题、图片、链接和版式。剪贴板同时包含 HTML 和纯文本；浏览器必须允许剪贴板操作。
5. 点“保存到博客仓库”，工具会创建 `_posts/日期-标题.md`，若文章有图片也保存到 `img/article-studio/`。同名文章不会覆盖。检查本地文章后，点“发布到线上博客”，确认后工具会提交这篇文章及图片并推送到博客 GitHub 仓库；首次发布可能一起推送工具安装提交。网站更新取决于 GitHub Pages 构建。

## 边界

服务只监听本机 `127.0.0.1:4174`，文章和图片不经过第三方排版服务。发布按钮只允许 `master` 分支、指定的博客远端，且会阻止远端新提交或其他待推送提交。工具不会替你登录公众号或自动发布公众号文章。图片单张上限 5 MB、每篇最多 30 张，整次保存请求上限 16 MB。

排版灵感是经典书籍、现代编辑页和留白阅读等通用方向，不复制其他网站的具体模板。博客使用自己的 Jekyll 排版样式；公众号使用复制时的内联样式，两个平台的显示可能有细微差异。
